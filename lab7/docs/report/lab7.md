### Комп'ютерний практикум №7

Практикум присвячений **колективним** операціям MPI, **паралельному множенню** $C = A \cdot B$ у **Python** (**mpi4py**, **numpy**) та **експерименту** з порівняння часу для різних схем обміну. Теорія узгоджена з лекційними матеріалами курсу та методичними вказівками до практикуму №7.

---

### Завдання 1

Потрібно **ознайомитись** із колективним обміном типів «**один-до-багатьох**», «**багато-до-одного**», «**багато-до-багатьох**» згідно з лекцією та документацією MPI (п. 1 методичних вказівок).

**Колективні** виклики виконуються узгоджено всіма процесами комунікатора. **Point-to-point** (`MPI_Send` / `MPI_Recv`) до колективів не належать; такий обмін використано в завд. 3 лише для порівняння.

**Один-до-багатьох.** `MPI_Bcast` — однаковий буфер від root усім; `MPI_Scatter` / `MPI_Scatterv` — розбиття масиву з root по процесах; `Scatterv` задає нерівні блоки через `counts` і `displs` (розподіл рядків $A$ при $N \not\equiv 0 \pmod P$).

**Багато-до-одного.** `MPI_Gather` / `MPI_Gatherv` — збір фрагментів на root; для збору $C$ на ранзі 0 використовується `Gatherv` з тими ж `counts` / `displs`.

**Багато-до-багатьох.** `MPI_Allgather` / `MPI_Allgatherv` — однаковий повний результат на всіх; `MPI_Alltoall` / `MPI_Alltoallv` — перестановка блоків між процесами. У завд. 3 застосовано `Allgatherv`, щоб повний $C$ був на кожному процесі.

**Таблиця 1.1** — Патерни обміну в контексті $C = AB$ (розподіл по рядках $A$).

| Патерн | Учасники | Примітиви MPI | Роль |
| ------ | -------- | ------------- | ---- |
| Один-до-багатьох | root → усі | `Bcast`, `Scatter`, `Scatterv` | $B$ усім; рядки $A$ по процесах |
| Багато-до-одного | усі → root | `Gather`, `Gatherv` | збір $C_{\mathrm{loc}}$ у $C$ на 0 |
| Багато-до-багатьох | усі ↔ усі | `Allgather`, `Allgatherv`, `Alltoall` | повний $C$ на всіх або перестановка блоків |
| Парний обмін | пари рангів | `Send`, `Recv` | порівняльний варіант (завд. 3) |

**Висновок (завд. 1).** Закріплено класифікацію колективів MPI і відповідність примітивів етапам паралельного множення матриць.

### Завдання 2

Потрібно реалізувати **паралельне множення** $C = A \cdot B$ у MPI з **колективним** обміном (п. 2 методичних вказівок).

**Алгоритм.** На ранзі **0** зберігаються повні $A$ і $B$. **`MPI_Scatterv`** роздає блоки рядків $A$; **`MPI_Bcast`** — матрицю $B$ усім процесам; локально $C_{\mathrm{loc}} = A_{\mathrm{loc}} B$; **`MPI_Gatherv`** збирає фрагменти $C$ на root. Розподіл рядків блоковий; при $N \not\equiv 0 \pmod P$ висоти блоків відрізняються не більш ніж на один рядок.

Реалізований варіант позначено як **`collective_sbg`**. **Коректність** перевірена порівнянням з `numpy` на тестових даних під час демонстраційного запуску програми.

### Завдання 3

Потрібно **дослідити ефективність** при зміні розміру матриць і кількості процесів і **порівняти** обмін «один-до-одного», «один-до-багатьох», «багато-до-одного», «багато-до-багатьох» (п. 3 методичних вказівок).

**Режими.**

| Код | Схема обміну |
| --- | ------------ |
| `p2p` | `Send` / `Recv` для $A$, $B$, $C$ |
| `collective_sbg` | `Scatterv` + `Bcast` + `Gatherv` (завд. 2) |
| `p2p_gatherv` | роздача P2P, збір $C$ — `Gatherv` |
| `allgatherv` | як `collective_sbg`, збір $C$ — `Allgatherv` |

**Що вимірюється.** На ранзі **0** — час між **`MPI_Barrier`** до й після фази комунікації та локального множення (**`MPI.Wtime`**). Для кожної пари $(N, P)$ у таблицю заноситься **мінімум** із **5** прогонів. Запуск здійснювався через `mpirun` з окремим виконуваним модулем бенчмарку; режим і розмір матриці задавалися змінними середовища.

**План експерименту.** Квадратні матриці $N \times N$, $N \in \{100, 150, \ldots, 1000\}$ (крок 50), $P \in \{2, 3, \ldots, 8\}$. Усі отримані значення зведено в таблиці нижче та у графіки (**рис. 3.1–3.6**).
